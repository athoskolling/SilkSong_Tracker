How a player reaches each screen

  1. TrackersAny page, header

    The new entry sits between Route and Account and backup. Regions, Route and Account and backup keep their names, order and addresses.

  2. Tabs for each typeTrackers

    Each tab shows its own count. A plate beside the tabs (below them on a phone) links to Rosaries and to the Build picker.

  3. Crumb "All trackers"Rosaries and Build picker

    Both sit under Trackers, so the header keeps Trackers marked. The crumb above the title leads back, the way "All regions" does on a Region.

  4. Link to the Build pickerCrests tab

    The tab where a Crest is marked also links straight to the picker, so a player does not have to find it in the plate.

Checked with option A at 390, 360 and 320px wide: the header stays on one row, inside the 124px the hero already reserves on a phone, and nothing scrolls sideways. Option A is the only change to an existing stylesheet (components.css). Option B changes the hero padding on every page instead.
