# Region hero images

One file per Region: `img/regions/<region-id>.jpg`, 16:9, at least 1920 × 1080, under about 400 KB, no HUD or text.
Every image needs a `heroCredit` in `data/regions.json`. Full rules: `docs/IMAGES.md`.
